# Contributing

Contributions are accepted under the same terms as the project: dual-licensed under the MIT license and the Apache
License, Version 2.0, at the recipient's option.

Before contributing, read [docs/legal/CLEAN_ROOM.md](docs/legal/CLEAN_ROOM.md). Code must be written from the specs in
`specs/` and your own observation of the games, never copied or translated from other projects' source. Never add
game data, disc images, extracted files, keys or packaged builds. Run `python tools/audit/audit.py` before opening a
pull request.
