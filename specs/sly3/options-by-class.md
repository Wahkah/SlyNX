# Sly 3 options by class

Read [../sly2/options-by-class.md](../sly2/options-by-class.md) first: options apply in order after the class
defaults, a later option of the same ID overwrites an earlier one (except list-adding options), and option lists
also occur inside placement records. Encoding: [object-stream.md](object-stream.md) 1; script access and the class
map: [scripts.md](scripts.md) 5. Tags as in [guards.md](guards.md).

## 1. How options apply

- **Option table** [X]: 40-byte entries at `0x0032CA80 + 40 × ID`. Word 0 is the value type, word 1 the flags, and
  word 6 the field written (flag `0x80` set) or, for a method (flag `0x400`), the argument count; words 5 and 7 are
  setter routines. A value type of `0x2000` plus a class number is a reference to an object of that class (for
  example `0x2087` a command script, `0x2082` an animation clip, `0x209E` a screen object) [X for the types, I for
  the reading as a class constraint].
- **Script access**: through the class map at `0x002ED518`; script IDs from 1,816 up are custom properties
  ([scripts.md](scripts.md) 5) [X] [R].
- **Placement blocks** apply options to the placed copy's objects, as in Sly 2 [R]; a placement's own OID names its
  copy's root ([scripts.md](scripts.md) 5) [X].
- **Option sets** of the world (fog, shadow, grading, clear colour) are not object options; they are listed in
  [rendering.md](rendering.md) 6 and [world-file.md](world-file.md) 3.7.

## 3. Which options each class uses on the disc [D]

Each entry is `ID (bodies)`: the number of bodies of that class whose own option list holds the ID (an ID can
repeat in a list, so counts can exceed the class's bodies). `[pN]` adds N option blocks inside placement records
whose target has that class. Counts are over every depth: bodies nested in solids, placements, zones, groupers
and state machines, and the components of effects (classes 191 and 192). The group name after each class is its
commonest owner ([object-stream.md](object-stream.md) 3).

Totals: 147 classes carry options; 1,719 class/option pairs; 972 distinct option IDs, the highest 2,043; 581,582 option occurrences, 2,440 of them in placement blocks.

The paths (9 to 13), the volume (7), the zone (14) and the state machine (132) were parsed field by field (their
option list follows variable data: points, collision mesh and tree, or nested objects); every body of them ends
exactly after its list. Bodies with an empty list: volume 20 of 25, paths 2,673 of 2,711 (class 9), 15 of 119 (10),
3 of 14 (11), 147 of 186 (12), 215 of 222 (13), zones 5 of 624, state machines 2,512 of 2,846.

Classes whose bodies carry no options on the disc: 16, 20, 29, 39, 72, 117, 121, 123, 128, 143. The placement
class 8 has only its blocks, counted under their target classes.
